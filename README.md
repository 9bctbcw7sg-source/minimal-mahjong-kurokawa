# ミニマル麻雀 黒川

生成り・乳白色・墨色・淡い灰色で構成した、ブラウザ完結の四人打ち麻雀ゲームです。外部APIやゲームサーバーは使わず、プレイヤー1人と簡易AI3人でチー・ポン・カンを交えながら、半荘戦または東・南・西・北を通す一荘戦を進行します。

## 起動方法

Node.js 22.13以降を用意し、次を実行します。

```bash
npm install
npm run dev
```

表示されたローカルURLをChromeで開いてください。

## GitHub Pagesで公開する

この公開版はサーバーや外部APIを必要としないViteの静的サイトです。`main`ブランチへpushすると、同梱のGitHub Actionsが検証・ビルド・GitHub Pagesへの公開を自動実行します。

詳しい初回設定は [PUBLISHING.md](./PUBLISHING.md) を参照してください。

## 検証方法

```bash
npm run lint
npm run typecheck
npm test
npm run test:e2e
npm run build
```

E2Eテストは、Macにインストール済みのGoogle Chromeを使用します。

## 今回置いた仮定

- プレイヤーは常に東家で、東一局開始時に14枚目をツモった状態から始めます。
- 136枚から14枚を王牌として分け、残る69枚を配牌後の通常牌山とします。カン時は王牌から嶺上牌を取得し、通常牌山末尾の1枚を王牌へ補充します。
- 最初のドラ・裏ドラ表示牌に加え、カンのたびに対応する新ドラ・新裏ドラ表示牌を1組開きます。裏ドラはリーチ和了時だけ開示・加算し、ドラだけでは和了役になりません。赤ドラは未実装です。
- 一発はリーチ宣言後、自分の次の打牌まで有効とし、途中で誰かがチー・ポン・カンをすると消滅します。通常牌山の最後のツモを海底、そこからの最後の打牌を河底として判定します。嶺上牌は海底として扱いません。
- 鳴きは初期設定でオンです。ロンを最優先し、次に放銃者から近い大明槓・ポン、最後に下家のチーを確認します。人間は候補または「見送る」を選び、AIは役牌の鳴きを優先し、それ以外は一定確率で鳴きます。
- 加槓は全員のロン確認を挟み、成立時は槍槓として扱います。暗槓に対する国士無双の例外的な槍槓と、四開槓による途中流局はまだ採用しません。
- チー・ポンの直後は、呼び出した牌と同種の牌に加え、両端からのチーで筋の入れ替えになる牌も捨てられない食い替え禁止を採用します。
- リーチは門前かつテンパイで持ち点1,000点以上の場合だけ宣言できます。宣言時に1,000点を供託し、その局の和了者が受け取ります。
- ロンは実装済みの役がある場合だけ可能です。複数の解釈がある牌姿は最も高い点数になる形を採用します。
- 点数は一般的な日本式リーチ麻雀を基礎とし、喰い下がり、食いタン、開いた刻子の符、七対子25符、場風と自風が重なる雀頭2符、4翻30符・3翻60符の切り上げ満貫、数え役満、複数役満を採用します。
- 初期持ち点は各家25,000点です。本場と供託を対局中保持し、和了または流局の結果に応じて自動更新します。
- 流局時は実際にテンパイしている全員がテンパイを申告するものとして、ノーテン罰符を自動精算します。
- 南四局で親が和了またはテンパイ流局した場合は連荘します。親がトップでも終了を選ぶアガリ止めは採用しません。
- 対局形式は半荘戦を初期値とし、一荘戦では南四局の次に西場、北場へ進みます。南四局または北四局で親が和了・テンパイ流局した場合は連荘し、親が流れた時点で規定終了です。
- 箱割れ終了は初期設定でオンです。局の精算後に誰かが0点未満になった場合に即終了し、0点ちょうどは続行します。オフなら規定最終局まで続けます。オカ、ウマは採用せず、同点時は開始時の席順で順位を表示します。
- 複数人がロン可能な場合は、放銃者から最も近い一人だけが和了する頭ハネルールです。
- AIはテンパイ時にリーチし、和了可能ならツモまたはロンを宣言します。役牌の鳴きを優先し、その他のチー・ポン・カンは控えめな確率で行い、打牌は孤立しやすい牌を優先します。
- 赤ドラは使わず、各数牌は同一牌4枚として扱います。
- 対局途中の状態は保存せず、LocalStorageには設定のみ保存します。
- 席を立つ操作は確認画面を挟まず、現在の一局を破棄して開始画面へ戻ります。

## 設計

- `src/game/tiles.ts`: 牌生成、表示名、整列
- `src/game/hand.ts`: 和了形、テンパイ、待ち牌、リーチ候補
- `src/game/scoring.ts`: 役、翻・符、満貫以上の上限、親・子の支払い、本場、供託
- `src/game/state.ts`: 洗牌、配牌、ツモ、打牌、ロン確認、チー・ポン・カン、嶺上牌、新ドラ、反応優先、食い替え、フリテン、持ち点、流局精算、半荘・一荘・箱割れ進行
- `src/game/ai.ts`: AIの打牌・鳴き選択
- `src/game/audio.ts`: ツモ・打牌・鳴き・リーチ・ロン効果音と将来の音声差し替え口
- `src/components/`: 表示とユーザー操作
- `tests/unit/`: ゲームロジックのVitest単体テスト
- `tests/e2e/`: Chromeで動かすPlaywright操作テスト

牌には種類・数字・4枚中の番号を含む一意なIDがあります。表示層は牌IDを指定して打牌・鳴き・カンを選び、ルール層が通常牌山と王牌を含む状態を更新します。和了形判定と点数評価も表示から分離しています。
